# Brand identity / version 1

VEXLUME — Beautiful Tools for Real Life.

Charcoal #171B1B, ivory #F2EDE4, muted gold #B99B67, sage #667D70, white #FFFFFF. Use dark text on light surfaces; gold is primarily a rule, border or accent rather than small body text. Sage on ivory is reserved for large editorial type and darkened for small labels.

Typography: Georgia editorial headings and an Arial/Helvetica/system sans-serif stack. No remote font requests, licensing dependencies or layout delay. The SVG cover system uses editable text and line motifs. The favicon is an original nested-V monogram; wordmark and social assets are included.

Art direction: tactile paper, editorial whitespace, restrained lines, warm daylight, everyday purpose. The original generated interior photograph is illustrative brand imagery, not a property project or customer testimonial. Generation brief: ivory travertine workspace, open journal, charcoal folio, brass pen, olive branches; natural editorial photography; no logo/text. Generated with the built-in image tool, optimized to WebP in `dist/assets/hero.webp`.

HAVEN connection: charcoal and gold, considered experiences. WILDWIRE connection: editorial hierarchy, independent ideas, real-life usefulness. No shared accounts, data integrations or dependency on sibling sites. Footer and editorial links connect outward only.

Product covers use a shared border, category, wordmark, serif title and a distinct line motif: home, spending bars, compass, weekly grid. Development covers for unreleased products are explicitly identified as concepts.
